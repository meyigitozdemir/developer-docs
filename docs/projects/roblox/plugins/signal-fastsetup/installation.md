# Installation

This guide explains the requirements and
setup process for Signal_FastSetup.

## Requirements

- Roblox Studio
- Access to the Script Editor

## Installing Signal_FastSetup

Obtain Signal_FastSetup from its official
distribution source.

::: info
The download link and exact installation
instructions will be added after the
distribution method is confirmed.
:::

## Automatic Signal Setup

Signal_FastSetup automatically places
the Signal module in `ReplicatedStorage`.

The module can be inspected using
Roblox Studio's Explorer.

## Verifying the Setup

1. Open Roblox Studio.
2. Open a script in the Script Editor.
3. Move to the beginning of a line.
4. Type `Seg`.
5. Check for the autocomplete suggestion.

If the suggestion appears, the autocomplete
feature is available.
