# Installation

Get started with **FastSignal**, a Roblox Studio plugin designed to simplify Signal module imports and setup.

## Requirements

Before installing, make sure you have:

- Roblox Studio installed on your computer.
- An active Roblox account.
- An internet connection.

## Step 1 — Open the Creator Store

Visit the official plugin listing:

**[FastSignal — Roblox Creator Store](https://create.roblox.com/store/asset/95297540676869/FastSignal)**

You can also search for FastSignal in the Roblox Studio Toolbox under Creator Store plugins.

## Step 2 — Install FastSignal

1. Open Roblox Studio.
2. Open the Toolbox and navigate to Creator Store plugins.
3. Find FastSignal.
4. Click **Install**, if available.
5. Complete any additional prompts.

Alternatively, follow the installation options available on the Creator Store listing.

## Step 3 — Verify Installation

After installing:

1. Open Roblox Studio.
2. Check your installed plugins.
3. Confirm that FastSignal is available.

You can now proceed to the User Guide for information about using the plugin.

## Troubleshooting

### Plugin not appearing

- Make sure installation completed successfully.
- Check the installed plugins list.
- Restart Roblox Studio.
- Verify that you are signed in to the correct Roblox account.

### Cannot access the plugin

Check whether the Creator Store listing is available to your account.

[Open FastSignal on Creator Store](https://create.roblox.com/store/asset/95297540676869/FastSignal)
