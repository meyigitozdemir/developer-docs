# Signal_FastSetup

**Less setup. Faster scripting.**

Signal_FastSetup is a Roblox Studio plugin
designed to simplify importing the Signal module
into your scripts.

It combines autocomplete assistance with
automatic Signal module installation.

## Overview

Importing the same module across multiple scripts
can become repetitive.

Signal_FastSetup streamlines this process by
providing an autocomplete shortcut that inserts
a Signal require statement.

The plugin also automatically places the Signal
module in `ReplicatedStorage`.

## Features

### 1. Smart Autocomplete

Type `Seg` at the beginning of a line
in the Roblox Studio script editor.

An autocomplete suggestion becomes available
for importing Signal.

### 2. Automatic Require

Accept the autocomplete suggestion to insert
the Signal module require statement.

### 3. Automatic Module Setup

Signal_FastSetup automatically places the
Signal module inside `ReplicatedStorage`.

## How It Works

1. Open a script in Roblox Studio.
2. Start a new line.
3. Type `Seg`.
4. Accept the autocomplete suggestion.
5. The Signal require statement is inserted.
