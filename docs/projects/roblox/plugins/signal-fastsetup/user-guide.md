# User Guide

Learn how to use Signal_FastSetup
to simplify Signal module imports.

## Quick Start

### Step 1: Open a Script

Open any supported script in the
Roblox Studio Script Editor.

### Step 2: Type the Shortcut

Move to the beginning of a new line
and type:

```text
Seg
```

### Step 3: Accept Autocomplete

Signal_FastSetup provides an autocomplete
suggestion for importing Signal.

Select and accept the suggestion.

### Step 4: Use Signal

The plugin automatically inserts the
Signal module require statement.

You can then use the imported module
according to its own API.

## Example Import

A typical require statement for a Signal
ModuleScript in ReplicatedStorage is:

```luau
local Signal = require(
    game:GetService("ReplicatedStorage")
        :WaitForChild("Signal")
)
```

::: warning Example
This is an illustrative Luau import.
The exact snippet generated by Signal_FastSetup
will be documented after verification.
:::

## Automatic Module Installation

Signal_FastSetup also automatically places
the Signal module in ReplicatedStorage.

You can verify its location in Explorer.

## Troubleshooting

### Autocomplete Does Not Appear

- Confirm that the plugin is installed.
- Open the Roblox Studio Script Editor.
- Type `Seg` at the beginning of a line.

### Signal Module Cannot Be Found

Check whether the Signal ModuleScript is
present in ReplicatedStorage.
